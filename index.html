How it works

Three steps. No manual logging, ever.

1

Connect your watch

Link Garmin or COROS once. RUNDEX reads each run as it syncs.

2

Run

Easy days, long days, races. Everything counts, and rest days are allowed.

3

Watch it move

Your value updates, a one-line stamp lands in your Strava activity description, and your friends' board reshuffles.

What moves your value

Your routine sets a fair value and your number is pulled toward it. Do the same thing every week and it sits still; change something and it moves.

+

Volume

Your average kilometres over the last four weeks set your fair value. Hold it and your value holds; lift it and your value follows.

+

Intensity

A faster-than-usual day gives a bump that fades unless you keep it up.

+

Consistency

Run days per week count as much as kilometres. Under two days a week and your fair value takes a cut.

++

Events

A race or a personal best moves the value sharply.

−

Going quiet

A small daily slide once you've been idle more than two days in a row. Ordinary rest days cost nothing.

±5

Daily cap

No single day moves you more than five percent either way.

    Formula weights

    The formula, in plain terms 
    Your last 28 days set a FAIR VALUE. Each day your value is pulled toward it.
Same routine → same fair value → flat line. Change the routine and it moves.

  fairValue   = start × ( 0.5
                        + volumeWeight      × (km per week, 28-day average) ÷ 10
                        + consistencyBonus  × (run days per week, 28-day average) )
                × (1 − penalty%) if you average under 2 run days a week

  pull%       = pullRate × (fairValue ÷ value − 1) × 100
                (closes a fraction of the gap every day, up or down)

Temporary shocks on a run day — the pull unwinds them over the following weeks:
  intensity%  = intensityWeight × (referencePace ÷ thisPace − 1) × 100, capped ±2
                referencePace = your median pace, last 8 weeks, similar distance, same run type
                paces are age-graded before comparing
  event%      = eventBonus for a race, or a PB (fastest ever within ±10% of this distance, by ≥1%)
                at most one every 14 days; no PB bonus for a lone run in 7 days

On a day without a run (on top of fair value falling as the 28-day window empties):
  idle        = consecutive days without a run
  decay%      = 0 if idle ≤ restTolerance, otherwise −decayRate × (1 + 0.25 per extra day), max 3×

  value_today = value_yesterday × (1 + move% ÷ 100), move capped at ±dailyCap

Friends are scored with exactly the same formula and weights.
